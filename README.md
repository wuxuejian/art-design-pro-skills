# Art Design Pro Codex Skills

本 Skill 根据 Art Design Pro 官方文档和 `Daymychen/art-design-pro` 当前 `main` 分支 `src/components/core` 源码整理。

核心资料：
- https://www.artd.pro/docs/zh/guide/introduce.html
- https://www.artd.pro/docs/zh/guide/essentials/project-introduce.html
- https://github.com/Daymychen/art-design-pro/tree/main/src/components/core

安装：将整个目录复制为 Codex 的 skill 目录，例如：

`~/.codex/skills/art-design-pro/`

目录：

```text
art-design-pro/
├── SKILL.md
└── references/
    ├── architecture.md
    ├── components.md
    ├── forms.md
    ├── tables.md
    ├── charts.md
    ├── cards-banners.md
    └── others.md
```
